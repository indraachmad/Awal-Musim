# Landing Page — Sudah Hujan, Apakah Sudah Masuk Musim Hujan?

Landing page statis untuk GitHub Pages yang menampilkan infografis edukasi mengenai perbedaan **kejadian hujan** dan **penetapan awal musim**.

## Struktur
- `index.html` — halaman utama
- `styles.css` — desain responsif
- `script.js` — animasi ringan
- `assets/` — logo dan dua versi gambar infografis

## Deploy ke GitHub Pages
1. Buat repository baru, misalnya `edukasi-musim-hujan`.
2. Upload seluruh isi folder ini ke branch `main`.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Simpan; GitHub akan memberikan URL GitHub Pages.

## Catatan isi
Halaman menggunakan kriteria awal musim yang dijelaskan dalam Pedoman Musim BMKG: untuk AMH terdapat skenario tiga dasarian berturut-turut ≥50 mm, serta skenario alternatif dengan dasarian pertama ≥50 mm dan total tiga dasarian ≥150 mm; AMK memiliki ketentuan kebalikan yang relevan.

## Catatan penggunaan identitas BMKG
Halaman ini diberi label sebagai materi edukasi dan **bukan halaman resmi BMKG**. Jika dipublikasikan menggunakan logo/identitas BMKG atau materi resmi BMKG, pastikan penggunaan tersebut mengikuti ketentuan atribusi dan penggunaan BMKG yang berlaku.
